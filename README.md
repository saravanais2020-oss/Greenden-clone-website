# Greenden-clone-website


Project Name: Greenden (HTML & Tailwind CSS)

Overview:
Greenden is a responsive, multi-page website designed using HTML and Tailwind CSS. It focuses on creating a clean, modern user interface that introduces practical web design concepts and responsive layouts. The project emphasizes Tailwind’s utility-first approach to build flexible and visually appealing designs.

Website Structure:

Home Page: Welcomes users with an attractive layout and a brief introduction to Greenden.

Products Page: Displays green-themed or plant-related products in a neat grid or card layout.

Contact Page: Provides organized contact information and a styled user interaction form.

Responsive Design:

Fully responsive layout adapting seamlessly to mobile, tablet, and desktop screens.

Built using Tailwind’s responsive classes (sm:, md:, lg:) for smooth viewport adjustments.

Ensures professional spacing, alignment, and typography across all devices.

Key Features & Learning Outcomes:

Multi-page responsive website design using Tailwind CSS.

Practical experience with flexbox, grid layouts, spacing, and text utilities.

Writing clean, maintainable HTML and Tailwind classes.

Gaining confidence in creating user-friendly, aesthetic, and accessible interfaces.

Outcome:
By completing Greenden, you gain hands-on experience in building a modern, responsive website. The project enhances your portfolio with a polished web design demonstrating practical skills in HTML and Tailwind CSS.
